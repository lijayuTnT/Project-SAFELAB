# Project SAFELAB

Static XSafe AI project website inspired by the provided reference images.

## Preview

Open `index.html` directly in a browser, or run a local static server:

```bash
python3 -m http.server 4173 --bind 127.0.0.1
```

Then visit:

```text
http://127.0.0.1:4173/
```

## Files

- `index.html` - page structure and content
- `styles.css` - layout, responsive styles, and flywheel animation
- `script.js` - hero safety-layer canvas animation
